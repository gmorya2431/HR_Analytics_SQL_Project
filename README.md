# HR Analytics SQL Project

## Project Overview
This project focuses on analyzing employee data using **MySQL** to identify workforce trends, salary patterns, employee performance, leave utilization, hiring trends, and employee attrition.

The goal is to generate meaningful business insights that can support HR decision-making.

## Dataset Overview
The project contains 6 relational tables with a total of **10,477 records**.

| Table | Records |
|---|---:|
| departments | 10 |
| jobs | 19 |
| employees | 1,054 |
| leaves | 4,234 |
| performance_reviews | 2,853 |
| salary_history | 2,307 |
| **Total** | **10,477** |

## Key Business Insights

- **Overall Attrition Rate:** 9.11% (96 out of 1,054 employees).
- **Highest Department Attrition:** Operations, with 14.02%.
- **Highest Number of Resignations:** Engineering, with 28 employees.
- **Highest Average Department Salary:** Executive, at 588,500.
- **Highest Average Performance Rating:** Operations, at 3.46.
- **Largest Employee Group:** Employees aged 35–44, representing 36.15% of the workforce.
- **Gender Distribution:** Male employees account for 51.71%, while female employees account for 48.29%.
- **Hiring Trend:** 2016 recorded the largest year-over-year increase in hiring.
